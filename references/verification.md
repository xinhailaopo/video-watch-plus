# 三路互校 playbook

本文件是本技能的方法论核心：**如何避免给出"看起来很专业但其实是编的"结论。**

---

## 一、为什么需要互校

三类证据各有各的失败模式，而且失败时都**不会报错**：

| 路 | 失败模式 | 表现 |
|---|---|---|
| 视觉（模型看图） | 分辨率不足时**渲染一个合理内容** | 图版里 16px 的字"读出"九个不同值；"读出"画面上不存在的标题 |
| 音频（ASR） | 无语音时**拿最常见模板句填空** | 多个互不重叠的时间窗输出完全相同的文本 |
| 量测（ffmpeg） | 素材特征与判据不匹配时静默给空集 | 低亮度对比的硬切，`scdet` 报 0 个切点 |

共同点：**它们都不会说"我不知道"。** 所以必须由外部规则来交叉校验。

---

## 二、各路的权威范围（不要越界引用）

### 量测层 —— 只信它的**时间**

`vw.py probe` 给你：切点、冻结段、静音段、逐秒运动量、像素突变、内容判型。
这些是从全部帧算出来的，**零 token**，也**不需要模型**，因此最可信。

权威范围：**时间与结构**。先后顺序、边界时刻、哪段静止、哪段在动。

**但它也会判空**：实测一段低亮度对比的三段式素材，`scdet` 报 `切点 0 个`。
这时工具会主动给出替代口径（"本素材无硬切点：采样必须由运动曲线与骨架承担"）并把内容判型
改为"低运动屏幕录制"。**遇到工具给出替代口径时，要顺着它的口径走，不要拿另一个口径的结论硬套。**

### 画面文字 —— 只有**裁切放大后我亲自看**的才算数

流程固定为：`vw.py read --region "x,y,w,h"` 或抽全分辨率帧 → 我看 → 才敢引用。

**图版（`grid.png`）里的文字一律不采信。** 实测：我在 149px 的 5×5 格子里把
「这用户怎么有股味儿啊」读成了「这怎么有一股咖喱味啊」；抽全分辨率帧裁字幕带后才确认原文。

权威范围：**文字内容**（字幕、界面文案、文件路径、烧入的时间码）。

### 音轨 —— 必须先过声学关

顺序**不能颠倒**：

```
audio_probe.py（有没有人声）  →  asr_hallucination_check.py（说了什么）
```

权威范围：**说了什么**。但前提是声学层没有判为"音乐/纯音/静音"。

## 三、冲突仲裁规则

| 冲突 | 谁赢 | 依据 |
|---|---|---|
| 时间先后 | **量测** | 视觉印象不能决定谁先谁后，只信 manifest |
| 文字内容：画面字幕 vs ASR | **画面** | 实测 6 句里 ASR 错 3 句，全是同音/近音 |
| 有无语音：ASR 文本非空 vs 声学判为音乐 | **声学** | 文本非空 ≠ 有语音（幻觉） |
| 结论 vs 证据缺失 | **承认缺失** | 写"我没有可读信息"，不用推断填空 |

实测的仲裁收益（一次真实交付）：

| 画面字幕（权威） | ASR 转写 | 差异 |
|---|---|---|
| `claude账号又被封了怎么办` | `Cloud的帐号又被封了 怎么办` | 同音，claude→Cloud |
| `有了 大肥鱼` | `有了 大飞鱼` | 同音，肥→飞 |
| `这用户怎么有股味儿啊` | `酷怎么有股味啊` | **整句错**，漏「用户」 |

而 ASR 的**时间轴**是可用的（分段边界与字幕出现时机吻合）——所以正确的用法是
**采纳它的时间、修正它的文字**。

## 四、两类已确认的幻觉（附证据）

### 视觉域：分辨率不足时渲染合理内容

> 3×3 图版里 16px 的时间码我"读"出了九个不同值（回原图裁切放大后发现九格字面全同）；
> 另一次我"读"出一组结构规整的标题（如"文章概览/叙事结构/第 4 页（共 5 页）"），
> 放大后发现画面上根本没有这些字。

**防御**：任何要写进交付的文字，都必须来自全分辨率裁切。

### 音频域：无语音时输出相同模板句

```
P1  [ 0.00 →  2.00]  no_speech=0.440  '字幕by索兰娅'
P1  [30.00 → 48.00]  no_speech=0.735  '字幕by索兰娅'
P2  [ 0.00 → 15.56]  no_speech=0.508  '字幕by索兰娅'
```

三个互不重叠的时间窗，文本完全相同，而模型自报 `no_speech` 概率 0.44–0.74。

**防御**：
1. 先跑 `audio_probe.py`；
2. 再跑 `asr_hallucination_check.py`，用"唯一文本比"判定：
   - `unique_ratio == 1/len` 且段数 ≥2 → 幻觉
   - `unique_ratio ≥ 0.8` 且 VAD 有输出 → 可信
3. 两道关卡都过了才引用转写文本。

## 五、自证对账（值得每次交付都做一次）

把**已知真值**烧进素材，让工具的输出可以被逐条对账，而不是"看起来对"。

`scripts/build_testclip.py` 造的素材带 `ground_truth.json`，另有一层更硬的自证：
**运动段用了 `testsrc2`，其画面内含时间码**，于是

```
seq 条带内源画面显示 00:00.208 / 00:00.708
   → 加该段起点 3.0s = 绝对 3.208s / 3.708s
manifest 声称取样于 3.2s / 3.7s
   → 逐帧吻合 ✅
```

这比"再跑一遍看结果是否一致"更有价值：它能发现**系统性的时间戳映射错误**，
而重复跑同一段错误代码永远发现不了。

## 六、可复用的检查清单

交付前逐条自问：

- [ ] 所有引用的文字，是否都来自**全分辨率裁切**，而不是图版？
- [ ] 所有时间点，是否都来自 **manifest / timeline.json**，而不是视觉印象？
- [ ] 音轨结论之前，是否跑过 `audio_probe`？若判为音乐/纯音，是否已把 ASR 输出按幻觉处理？
- [ ] ASR 文本是否通过 `unique_ratio` 检查？
- [ ] 与画面字幕冲突时，是否以画面为准？
- [ ] 有没有哪个区段我其实**没有可读信息**，却写了推断？——把它标成推断或缺失。
- [ ] 做没做一次自证对账？
