## 二、量测层（`vendor/vw.py probe`）

```
素材 clip.mp4  640x360 24.0fps  9.00s  视频 h264  音频 aac
帧 216  实际帧率 24.00
内容判型 剪辑类（影视/演示/短视频）
切点 2 个  冻结段 2 个  静音事件 2 个
运动量 均值 1.689  p95 6.073  max 6.073  活跃秒占比 44%
```

| 验收项 | 基准真值 | 工具输出 | 判定 |
|---|---|---|---|
| 帧数 / 时长 | 216 / 9.00s | 216 / 8.958 | ✅ |
| 硬切点 | 3.0、6.0 | `cuts: [3.0, 6.0]` | ✅ **精确** |
| 冻结段起点 | 0.0、6.0 | `freezes: [0.0, 6.0]` | ✅ **精确** |
| 静音段 | 起 0.0 / 止 3.66 | `start 0.0` / `end 3.66` | ✅ **精确到帧** |
| 内容判型 | 含硬切的剪辑类 | 剪辑类（影视/演示/短视频） | ✅ |

> **一次反例同样记在这里。** 本仓库早期用的是"三段纯色"素材（低亮度对比），
> 同样的代码给出 `切点 0 个`，并把内容判型改为"低运动屏幕录制"。
> 这不是 bug——`scdet` 依据亮度差，纯暗色之间的切换确实不构成硬切。
> 工具**主动给出了替代口径**："本素材无硬切点：采样必须由运动曲线与骨架承担"。
> 造验收素材时要把对比度做够，或换用 `testsrc2`。

## 三、视觉层（`vendor/vw.py grid` + 我亲自 `read_image`）

`grid --frames 25 --cols 5` 产出一张 765×440 图版 ≈ 350 token。

**我实际看到的**（逐格）：

| 格区间 | 对应时间 | 画面 |
|---|---|---|
| 1–8 | 0.00–2.62s | 暗红底、文字 `SEG-1 IDLE` |
| 9–16 | 3.00–5.62s | 彩色测试彩条、`SEG-2 PLAY`，**各格彩条位置逐格变化 → 运动可见** |

与量测层的 `cuts: [3.0, 6.0]` 与人为真值**三方一致**。

## 四、声学层（`scripts/audio_probe.py`）

```
时长 9.0s  帧 277  帧率 31.25/s
响度 均值 -60.79 dBFS  峰值 -21.09  动态 98.91 dB  静音占比 40.1%
谱   质心 439.4 Hz  平坦度 3e-05  85%滚降 445.5 Hz  语音带占比 99.6%
节拍 187.5 BPM（自相关峰 0.0009）  响度波动 98.89 dB  音节率调制 0.76

判型 纯音/提示音（非语音、非音乐）（置信 medium）
  - 单音集中度 0.576（单一谱峰占该帧大部分能量）
  - 节拍自相关峰仅 0.001（无节奏结构）
  - 有声帧占比 59.9%
```

**两个独立对账**：

1. 谱质心 **439.4 Hz** —— 素材里注入的是 440Hz 正弦，量测误差 0.6 Hz。
2. 有声帧占比 **59.9%** —— 真值是 (9.00 − 3.66) / 9.00 = **59.3%**。

> **一次被记录下来的方法论缺陷及修复。** 本脚本第一版把**静音帧也算进谱指标均值**，
> 而静音帧的频谱本质是数值噪声（平坦度接近 1），于是同一段素材被算成
> 质心 1866 Hz、平坦度 0.40，判型退化为含糊的"可能含人声"。
> 修法是**只在有声帧（> −50 dBFS）上统计谱指标**，并新增 `active_frame_ratio` 字段与
> `tonal_concentration`（单音集中度）判据，把"纯音"单独分成一支。
> 修复后质心回到 439.4 Hz、平坦度 3e-05 —— 与"这是一段纯正弦"的事实一致。

## 五、幻觉证伪（`scripts/asr_hallucination_check.py`）

```
== 对照组：默认（开启 VAD）==
  → 0 段

== 实验组：关闭 VAD + 拆掉所有拒识门槛（强制出字）==
  [    0.00 →     2.00] no_speech=0.573 logprob=-0.99 | '字幕by索兰娅'
  → 1 段

== 判定 ==
  判定为幻觉：音轨很可能没有人声
   - VAD 模式无任何输出（该检测器不依赖语言模型）
   - 强制模式仅产出 1 段，模型自报 no_speech 概率均值 0.57
   - 强制模式内容：['字幕by索兰娅']（单段文本通顺不构成证据）
```

> **又一次被记录下来的规则缺陷。** 该脚本第一版要求"≥2 个时间窗输出相同文本"才判幻觉，
> 而这段素材只产出 1 段，于是落到"无法判定"。
> 修法是补上更强的一条独立证据组合：**VAD 无任何输出 + 模型自报 no_speech ≥ 0.4**。
> VAD 是不依赖语言模型的语音检测器，它和模型自身的 no_speech 概率是两条独立证据，
> 一致时"文本看起来通顺"不足以推翻它们。

## 六、三个素材上的总结论（防止规则只在单一素材上成立）

同一套脚本在三种性质完全不同的音轨上跑：

| 素材 | 声学判型 | 转写判定 | 是否正确 |
|---|---|---|---|
| 合成素材（40% 静音 + 纯 440Hz 单音） | 纯音/提示音（非语音、非音乐） | 判定为幻觉 | ✅ |
| 真实 B 站视频（48.27s，纯 BGM） | 器乐/音乐为主，未见人声特征（high） | 判定为幻觉 | ✅ |
| 真实 B 站视频（20.16s，有人声对白） | 声学量测未见明确人声特征，也未达音乐判据 | **转写可信：有真实语音** | ✅ |

关键判据的实测区分度：

| 指标 | 纯 BGM | 有人声 | 纯单音 |
|---|---|---|---|
| 节拍自相关峰 | **0.857** | 0.165 | 0.001 |
| 谱平坦度 | 0.00012 | 0.0227 | 3e-05 |
| 逐秒响度波动 (dB) | **6.33** | **19.1** | 98.89 |
| 85% 谱滚降 (Hz) | **466** | **1277** | 445 |
| 单音集中度 | 低 | 低 | **0.576** |
